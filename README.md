# Diabetic Foot Ulcer (DFU) Image Classification

## Project Overview
This project focuses on deep learning-based classification of Diabetic Foot Ulcer (DFU) images to assess ulcer severity using computer vision and machine learning techniques.

## Objectives
- Develop a deep learning model for DFU image classification.
- Classify images into four categories:
  - Normal Skin
  - Low-Risk Ulcer
  - Moderate-Risk Ulcer
  - High-Risk Ulcer
- Explore CNN and transfer learning architectures.
- Evaluate model performance using classification metrics.

## Technologies Used
- Python
- PyTorch
- TensorFlow
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Structure
- `notebooks/` – Model development and experiments.
- `src/` – Python scripts.
- `models/` – Trained model weights.
- `dataset/` – Dataset instructions and metadata.

## Model Evaluation
Performance is evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC (where applicable)
